# ODMFlow 合成定制能力与需求收集规则

> 本文为项目拟定的对话知识，不是实际工厂能力或合规承诺。“可讨论”不等于“已支持”，所有新增硬件、系统兼容性、认证和交期需正式评估。

## 客户可以提出哪些定制

| 类别 | 典型需求 | Agent 可做 | 必须升级评估的情形 |
| --- | --- | --- | --- |
| 外观/包装 | Logo、开机画面、包装文案、配色 | 记录素材、语言、商标授权和目标地区 | 结构件、模具或宣称防护等级变化 |
| Android/应用 | 预装客户 App、默认桌面、权限/设置项、OTA 维护目标 | 记录目标 Android 版本、App 安装与更新方式 | 系统镜像修改、兼容性/GMS 条件、系统签名权限 |
| 企业部署 | 单应用 kiosk、批量注册、策略管理 | 区分普通预装与受管设备，询问 MDM/EMM 提供方 | 真正的设备管理账号、许可证、远程擦除和安全策略 |
| 硬件/无线 | NFC、扫码、摄像、SIM/eSIM、频段、电池 | 记录必选项与可替代项，明确现有基线未核定 | 新器件、射频/天线、功耗、认证复测 |
| 区域化 | 系统语言、输入法、时区、插头/包装、当地应用 | 询问**具体销售国家**和是否为蜂窝版 | 市场准入、运营商、隐私/数据处理、GMS 国家可用性 |

## 区域问题的标准问法

1. 销往哪个**国家**，还是多个国家？不要仅记录“欧洲/东南亚”。
2. 手机还是平板？Wi-Fi、4G、5G 哪种连接？如蜂窝版，目标运营商是什么？
3. 消费零售、学校、企业专用设备还是公共展示？是否必须 GMS/Google Play、MDM/kiosk？
4. 语言、输入法、客户 App、包装和售后服务网络有哪些要求？
5. 是先要能力说明、技术评估、样机还是模拟订单申请？

## 判定措辞

- 可答：“这类需求属于我们**可受理评估**的定制范围；需要确认型号与目标国家后进行技术/合规评估。”
- 不可答：“所有型号都支持”“已认证”“一定可在当地销售”“GMS 可直接安装”“该频段一定兼容运营商”。
- 欧盟咨询需提醒手机/平板类别、USB-C、能效/生态设计与无线电符合性核查；美国咨询需提醒 FCC、蜂窝/运营商核查；印度咨询需提醒 BIS 类别和本地语言要求。这里是**待办提醒**，不是具体产品的合规结论，这些项目核查提醒不构成任何国家的法规清单或法律意见；应由合规人员复核当地适用要求。
